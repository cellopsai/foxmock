Features

Everything You Need to Mock

Built for developers who want to test fast without leaving their IDE.

🌐

REST / HTTP Mocking

Mock any endpoint in seconds. Set the method, path, status code, headers, and JSON body. Supports wildcards and regex routes.

GET · POST · PUT · DELETE · PATCH
📄

Import from OpenAPI Spec

Drop in a .yaml or .json OpenAPI spec and FoxMock instantly creates all routes with pre-populated scenarios for every response code defined in the spec.

OpenAPI 3 · Swagger 2 · YAML · JSON
⚡

gRPC Mocking

Load a .proto file and FoxMock auto-discovers all services and methods. Returns JSON-transcoded responses just like a real server.

proto3 · Unary · Streaming
📁

SFTP Mocking

Simulate a full SFTP server with configurable file listings, upload and download responses. Test file-transfer workflows without SSH keys or a real server.

Upload · Download · List · Stat
✉️

SMTP Mocking

Capture outbound emails from your app without sending a single real message. Inspect subject, headers, and body in the transaction log — perfect for testing email flows.

Capture · Inspect · Headers · Body
🎭

Multiple Scenarios

Define named scenarios per method: success, error, slow response. Switch the active scenario with one click — no code change, no restart.

● Active · ⚡ Conditional · Disabled
🎯

Conditional Auto-Switching

Match on request body content with JSONPath, regex, or exact comparisons. The right scenario is served automatically based on what the caller sends.

JSONPath · Regex · Exact Match
🤖

AI Response Generation

Generate realistic mock data using OpenAI, Claude, Ollama, or any local CLI. Field names are inferred — email gets an email, id gets a UUID.

OpenAI · Claude · Ollama · Local CLI
💾

Save & Load Collections

Persist your entire mock setup to a .foxmock or .foxmock-grpc JSON file. Commit it to git — the whole team loads the same config in two clicks.

.foxmock · .foxmock-grpc · JSON
📊

Transaction Log

Every request is logged with method, path, matched scenario, status code, and duration. Confirm your app is hitting the mock and debug mismatches instantly.

Real-time · Scenario matched · Duration
⏱️

Latency Simulation

Add artificial delay to any scenario in milliseconds. Reproduce slow network conditions and timeout edge cases without a VPN or a flaky external service.

Per-scenario delay · 0–∞ ms
🔌

Zero External Processes

Runs entirely inside IntelliJ on a single port. No Node.js, no Docker, no WireMock JAR. Install the plugin and you're done.

localhost · Configurable port
Getting Started

Up and Running in 60 Seconds

1

Install the Plugin

Search FoxMock in the JetBrains Plugin Marketplace and click Install.

2

Define Your Mock

Open the FoxMock tool window, add a route or load a .proto file, set your response.

3

Start the Server

Click Start Server. FoxMock starts each protocol on its own configurable port — HTTP, gRPC, SFTP, and SMTP simultaneously.

4

Start Developing

Point your client at FoxMock. It responds exactly like the real service would.

Scenarios

One Mock, Many Responses

Create named scenarios for each endpoint — happy path, error, timeout, edge case. Switch between them instantly without editing code or restarting anything.

Combine with conditional matching to serve different scenarios based on what the request contains — automatically.

Conditional Matching

Serve the Right Response Automatically

Write match conditions on request body content. When a request matches, FoxMock routes to that scenario — no manual switching needed in automated tests.

Use JSONPath to drill into nested fields, regex for flexible patterns, or exact body matching for strict assertions.

Learn about Conditions →
Body JSONPath $.role Equals "ADMIN"
Body JSONPath $.user.id Exists
Body Regex (body) Matches ".*error.*"
→ All conditions use AND logic. Priority controls evaluation order.
