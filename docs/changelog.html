Changelog

All notable changes to FoxMock are documented here. FoxMock is currently in free public beta — every feature is included at no cost.

1.0.0-beta.3 Latest May 18, 2026

gRPC Scenario Management — Full Parity with REST

  • Enabled / disabled flag per gRPC scenario — uncheck Enabled in the Configure dialog to take a scenario out of rotation without deleting it. Disabled scenarios appear gray and italic and are skipped at all three resolution tiers.
  • Conditions tab in gRPC Configure dialog — add, edit, and remove match conditions (Body JSONPath, Body Regex, Body Exact) directly in the gRPC scenario editor, with the same UX as the REST panel.
  • Priority spinner — control the evaluation order of conditional gRPC scenarios; lower number = higher priority.
  • Visual role badges — ● active fallback, ⚡ conditional, ⚡● both, dimmed = disabled. Badge rendering is now consistent across REST and gRPC panels.
  • Scenario rename — rename a gRPC scenario from the Configure dialog name field without recreating it.
  • Three-tier resolution fully enforced for gRPC — the enabled flag is checked before a conditional scenario can win Tier 1; disabled scenarios can no longer accidentally fire.

gRPC — Save / Load Config

  • Save Config button in the gRPC panel exports all services, methods, scenarios, conditions, and priorities to a .foxmock-grpc JSON file.
  • Load Config button restores the full scenario set from a .foxmock-grpc file. Methods not found in the currently loaded .proto are skipped and listed in the confirmation dialog.
  • Commit .foxmock-grpc alongside your .proto files — the whole team loads the same mock setup in two clicks.

HTTP Mock Panel

  • 📖 Tutorial button — opens the Mock REST APIs with Query Params & Scenarios tutorial in the default browser directly from the HTTP Mock panel toolbar.

UI Redesign — IntelliJ-Style Panel Layout

  • Flat section headers — all four mock panels (HTTP, gRPC, SFTP, SMTP) now use bold 12 pt labels with a 1 px theme-aware divider instead of raised titled borders, matching standard IntelliJ tool window style.
  • Inline connection info strip — server address, port, and credentials shown in a compact gray strip immediately below the toolbar.
  • HTTP — vertical split — routes and request log are always visible in a OnePixelSplitter with a draggable divider; no tab switching required.
  • HTTP — flat route table — one row per route shows method, path, and the active scenario name inline; accordion expansion is gone.
  • HTTP — group collapse / expand — single-click a group header to collapse (▶) or expand (▼) it; double-click still opens the rename dialog.
  • HTTP — smart search — IntelliJ SearchTextField replaces method-filter chips; understands GET, /api/users, or POST /orders queries.
  • SFTP — "Add File" and "Refresh" moved into the Mock Files section header.
  • gRPC — "Load Proto" moved into the Proto Files section header.
  • SMTP — "Clear Inbox" moved into the Inbox section header.
  • All panels — "Clear" button moved into the log section header.

New Feature — CLI AI Provider (No API Key Required)

  • Added a CLI AI provider that pipes the generation prompt to any AI command-line tool already installed on your machine — no API key or cloud account needed.
  • Supported out of the box: claude, ollama run <model>, llm, sgpt, aichat, or any custom shell command that reads from stdin and writes to stdout.
  • Auto-detect — click Detect available CLIs… in Settings → Tools → FoxMock to scan your PATH and pick from found tools.

Richer AI Context for HTTP Routes

  • When the CLI provider is active, FoxMock scans Java and Kotlin source files in the open project and automatically includes matching controller source code in the prompt — giving the model accurate field names and business context.
  • Controller detection matches on route path and Spring MVC / JAX-RS annotations.
1.0.0-beta.2 April 2026

Bug Fix — Conditional Scenario Auto-Matching

  • Fixed a critical bug where setting a scenario as the default fallback incorrectly disabled all other scenarios including conditional ones — causing Tier 1 auto-matching to never fire.

Richer Request Inspector

  • HTTP log now shows query string, matched scenario name, and request body as indented detail lines beneath each transaction.
  • gRPC log now shows proto request and response types per call.
  • Errors rendered on a bold-red line with ✕ prefix across HTTP, gRPC, and SFTP inspectors.
  • Log panels replaced with a styled console view — monospaced font, IDE-theme background, syntax-coloured HTTP methods and status codes (green 2xx, orange 4xx, red 5xx).

UI Polish & Discoverability

  • All split panes use a 1 px theme-aware divider consistent with the IntelliJ UI.
  • .fmcoll.json collection files registered as a JetBrains file type — IDEs without FoxMock installed will suggest the plugin automatically when a collection file is opened.
  • Non-intrusive rating prompt appears once after 10 successful mock responses.
1.0.0-beta.1 Initial Beta April 2026

First public beta release of FoxMock.

REST / HTTP Mock Server

  • Dynamic routing with path variables ({name}) and wildcards
  • Multiple named scenarios per route — switch without restarting
  • Per-scenario status code, response body, custom headers, and artificial delay
  • Route enable/disable toggle and drag-and-drop route groups
  • Conditional scenario matching: query params, headers, request body (JSONPath, Regex, Exact)
  • Three-tier resolution: conditional → manually activated → first enabled
  • OpenAPI 3.0 / Swagger 2.0 import — generates routes and scenarios from spec
  • Enum query params expand into one scenario per allowed value with pre-wired conditions

gRPC Mock Server

  • Load .proto files and mock individual unary RPC methods
  • Multiple named scenarios per method with one-click switching
  • Live gRPC request inspector

SMTP Mock Server

  • Local SMTP server for testing email sending — inspect subject, headers, and body
  • Configurable port and credentials

SFTP Mock Server

  • Local SFTP server with configurable port, credentials, and root directory
  • Live SFTP request inspector

AI Response Generation

  • Providers: OpenAI, Claude (Anthropic), Gemini (Google), Ollama (local), CLI
  • API keys stored securely in the OS keychain via IntelliJ PasswordSafe

Developer Experience

  • Dashboard with one-click Start All / Stop All
  • cURL export from any route dialog
  • Collections — save/load sets of routes as .fmcoll.json files with per-route conflict resolution
  • Keyboard shortcuts: Alt+Shift+F start all, Alt+Shift+X stop all
  • Dynamically loadable — no IDE restart required after install
